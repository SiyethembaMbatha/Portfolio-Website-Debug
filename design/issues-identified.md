# Issues Identified in Starter Code

## HTML Issues
The starter code across all four pages (`index.html`, `about.html`, `projects.html`, `contact.html`) relies on generic `<div>` elements instead of semantic HTML5 tags. There is no `<header>`, `<nav>`, `<main>`, `<section>`, or `<footer>` anywhere, and no navigation menu exists on any page, so users cannot move between pages. All pages are missing `lang`, charset, and viewport meta tags, reducing accessibility and responsiveness. Images (`hero.jpg`, `profile.jpg`, `project1.jpg`, `project2.jpg`) all lack `alt` attributes, failing accessibility standards. The About page has no data table at all, despite one being required to display skills or experience. The Projects page only includes two projects instead of the required three. The Contact form has no `<label>` elements, relies on `placeholder` text as a substitute (which is not accessible), only offers two input types (text and textarea) instead of the required five, uses `type="text"` for the email field instead of `type="email"`, and includes no HTML5 validation attributes such as `required` or `pattern`.

## CSS Issues
The stylesheet only uses two selector types (element and class), well short of the required five (element, class, ID, descendant, pseudo-class). No pseudo-classes such as `:hover` or `:focus` are used anywhere, so there are no interactive states. Navigation styling is entirely absent since no navigation exists yet. Box model usage is minimal — margins and padding appear sparingly, and no `border` properties are used anywhere in the file. The footer is explicitly set to `text-align: left`, causing misalignment instead of a centered layout. There is no table styling, no form visual hierarchy beyond basic spacing, and no flexbox or grid layout techniques used. No media queries exist, despite responsive design being a requirement.

## Approach to Fixing
I will restructure all four HTML pages using proper semantic elements, add a consistent working navigation menu across all pages, add descriptive `alt` text to all images, build the missing skills table on the About page, add a third project card, and rebuild the contact form with labels, five input types, and HTML5 validation. On the CSS side, I will expand selector variety, add pseudo-classes for interactive states, fix the footer alignment using flexbox, demonstrate clear box model usage (margin, padding, border), style the navigation, table, and form, verify colour contrast meets 4.5:1, and introduce responsive layout techniques with media queries.
